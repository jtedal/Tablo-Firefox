# Работа над Табло

## Ветки

- `dev` — текущая разработка, исправления и изменения интерфейса.
- Коммиты и push выполняет пользователь самостоятельно. Готовить изменения локально, не создавать коммиты и не делать push без отдельной прямой просьбы.
- Сообщения коммитов писать на английском языке.
- `main` — только релизы. Изменять её при явно запрошенном выпуске версии.
- Перед работой проверять текущую ветку, индекс и незакоммиченные изменения. Сохранять изменения пользователя и не применять принудительный push.

## README и скриншоты

- При обновлении расширения актуализировать `README.md` и делать свежие скриншоты интерфейса. Готовить их вместе с соответствующим изменением.
- README предназначен для пользователей: короткое описание, возможности, установка и изображения. Инструкции по сборке и внутренние технические подробности хранить в `docs/DEVELOPMENT.md`.
- Скриншоты хранить в `docs/screenshots/`: `main.png`, `folder.png`, `weather-week.png`. Обновлять их после проверки финального интерфейса в Firefox.
- Снимать настоящее расширение в отдельном тестовом профиле с общедоступными сайтами. Не использовать личные закладки, аккаунты и изображения устаревшего интерфейса.
- Перед завершением проверять ссылки и пути к изображениям в README, а также соответствие описания работающей версии.
